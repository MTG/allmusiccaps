# AllMusicCaps

Music caption dataset built from professional AllMusic album reviews
cross-referenced with Discogs releases and YouTube tracks. Captions are
generated in two complementary styles by an LLM second-stage pipeline.

The dataset is distributed via the Hugging Face Hub at
[`mtg-upf/allmusiccaps`](https://huggingface.co/datasets/mtg-upf/allmusiccaps); only a
50-row sample is tracked in this repository, under `_samples/`.

## Versions

`allmusiccaps_v0.jsonl` is the file the paper's models were trained on, holding the raw
second-stage LLM output. In it, `generated_quotes_captions` is not consistently typed: for
4,123 rows the model returned a nested list, an attribute-keyed dict, or a bare number
instead of a list of strings, which makes Arrow-backed readers reject the file.

`allmusiccaps_v1.jsonl` normalizes that field to `list[string]` and is the default on the Hub.
Only the container changes: row order, row count, all identifier fields, and
`generated_structured_captions` are identical to v0. Regenerate it with
`scripts/preprocess_am_discotube/normalize_allmusiccaps_v1.py`.

## Schema

One JSONL row per (youtube_id, discogs_release_id) pair. Fields:

| Field | Type | Description |
|-------|------|-------------|
| `youtube_id` | string | YouTube video ID. |
| `discogs_release_id` | string | Discogs release ID. |
| `allmusic_album_id` | string | AllMusic album ID (`mwXXXXXXXXXX`). |
| `youtube_url` | string | `https://www.youtube.com/watch?v={youtube_id}`. |
| `discogs_release_url` | string | `https://www.discogs.com/release/{discogs_release_id}`. |
| `allmusic_review_link` | string | `https://www.allmusic.com/album/{allmusic_album_id}`. |
| `generated_quotes_captions` | list[string] or null | Quote-style captions extracted from the review by Qwen2.5-32B (chatgpt_v2 prompt, t=0.5). Each string is a self-contained caption sentence. |
| `generated_structured_captions` | object or null | Structured per-attribute caption from LLaMA-3.3 (promptv3). Keys: `music_style`, `mood`, `tempo`, `energy`, `instrumentation`, `production_style`. |

A row is emitted whenever at least one of the two caption sources is available; the missing source is set to `null`. Use `--require-both` in the build script to drop incomplete rows.

## Building the full release

The release file is generated by `scripts/preprocess_am_discotube/build_allmusiccaps_release.py`. Inputs (cluster paths):

| Input | Path |
|-------|------|
| Reviews + IDs | `<host>:/mnt/projects/allmusic/dumps/review/youtube-to-allmusic-review.json` |
| Quotes captions | `<login-node>:/scratch/<group>/discotube/metadata/Qwen_Qwen2.5-32B__chatgpt_v2__t0.5__1.1.jsonl` |
| Structured captions | `<login-node>:/scratch/<group>/discotube/metadata/llama33_promptv3_captions.jsonl` |

Example invocation (paths after staging the three inputs in one place):

```bash
python scripts/preprocess_am_discotube/build_allmusiccaps_release.py \
    --reviews /path/to/youtube-to-allmusic-review.json \
    --quotes  /path/to/Qwen_Qwen2.5-32B__chatgpt_v2__t0.5__1.1.jsonl \
    --struct  /path/to/llama33_promptv3_captions.jsonl \
    --out     data/allmusiccaps/allmusiccaps_v0.jsonl
```

## Coverage (v0)

Built 2026-04-28 from the inputs above. Total rows: **540,454**.

| Caption coverage    | Rows    |
|---------------------|---------|
| both quotes + struct | 245,346 |
| struct only          | 295,096 |
| quotes only          | 12      |

The full release file `allmusiccaps_v0.jsonl` (510 MB) is gitignored. `_samples/sample_50rows.jsonl` is a 50-row preview (head of the full release) committed to the repo so reviewers can inspect the schema without pulling the full file.
